# SAAD — Spice Invoice Management

واجهة عربية RTL لإدارة أصناف البهارات والفواتير وتقارير الماركت.

## الموجود في النسخة
- إضافة الأصناف وتعديلها وحذفها.
- سعر العبوة الواحدة قابل للتحديد، ويمكن تغييره أيضاً داخل الفاتورة.
- حساب الإجمالي تلقائياً.
- سجل الفواتير مع طباعة الفاتورة وحذف فاتورة منفردة.
- إدارة الماركت؛ حذف الماركت يحذف الفواتير المرتبطة به بعد تأكيد واضح.
- تقارير إجمالي مشتريات الماركت والصنف الأكثر طلباً ومشاركة التقرير عبر واتساب.
- تخزين محلي في المتصفح.
- دعم اختياري لتسجيل البريد والمزامنة السحابية عبر Firebase.

## التشغيل المحلي
افتح `index.html` في متصفح حديث. تحتاج اتصالاً بالإنترنت لتحميل Tailwind وFirebase من CDN والخط.

## تفعيل الحسابات والمزامنة بين الأجهزة (Firebase)
هذه الخطوات ضرورية؛ لا يمكن تفعيل حسابات حقيقية بمجرد HTML وحده.

1. أنشئ مشروعاً في [Firebase Console](https://console.firebase.google.com/).
2. أضف Web App وانسخ إعدادات Firebase.
3. من Authentication > Sign-in method فعّل Email/Password.
4. أنشئ قاعدة Firestore.
5. افتح `app.js` واستبدل القيم `PASTE_YOUR_...` في `FIREBASE_CONFIG` بقيم مشروعك.
6. انشر قواعد `firestore.rules` في صفحة Firestore Rules.
7. اختبر إنشاء حساب ببريد وكلمة مرور، ثم جرّب الدخول من جهاز آخر بالحساب نفسه.

**مهم:** لا تضع مفاتيح حسابات خاصة أو أسرار خادم في المستودع. إعدادات Firebase الخاصة بتطبيق الويب ليست بديلاً عن قواعد Firestore؛ القواعد المرفقة تقيد كل مستخدم بوثيقته الخاصة. بيانات المستخدم القديم المخزنة محلياً لا تُرفع تلقائياً إلى حساب جديد إلا بعد تسجيل الحساب لأول مرة على الجهاز الذي يحتويها؛ راجع البيانات قبل الاعتماد عليها.

## النشر على GitHub Pages
1. ارفع الملفات إلى مستودع GitHub.
2. افتح Settings > Pages.
3. اختر النشر من الفرع الرئيسي (`main`) ومن المجلد الجذر.
4. احفظ وانتظر رابط الموقع.
